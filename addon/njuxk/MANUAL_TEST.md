# 南大选课插件 人工实测清单

> 本清单覆盖 **只能人工验证**的部分：真实网络、真实登录、真实抢课。真实 API 需要校园网 + 学号账号 + 选课开放时间窗口，自动化代理无法执行，因此交付给用户自测。
>
> 所有离线可验证的逻辑（登录流程、批次/类别解析、课程解析、搜索排序、收藏、调度器状态机、信号接线等）已由 185 个自动化测试覆盖（`tests/`），不在本清单重复。
>
> 文档中的按钮文字、页面名称、提示文案均与当前实现（`main.py` / `ui/*.py` / `core/*.py` / `api/*.py`）一致。若实测与本文不符，请先确认插件版本，再按「四、失败排查表」定位。

## 一、前置条件

开始实测前，请逐项确认：

1. **校园网环境**：本机已接入南京大学校园网，或已通过 EasyConnect VPN 连接校内网络。插件客户端 `trust_env=False`，不走系统代理，必须能直连 `xk.nju.edu.cn`。
2. **zbProgram 已安装并能启动**：宿主程序运行正常（Python 3.13+，本插件在 3.14 下开发验证）。
3. **插件已正确放置**：开发态把插件目录放到 `D:\Code\zbProgram\addon\njuxk\`（目录名必须与 `addon.json` 中的 `id` 一致，即 `njuxk`）；或通过插件管理功能安装。
4. **依赖已安装**：在插件环境执行 `uv pip install onnxruntime pycryptodome`（`pillow` / `numpy` / `requests` 主程序已自带）。`onnxruntime` 缺失会导致验证码识别不可用，登录必失败。
5. **账号**：本人学号与统一身份认证密码（即登录 `xk.nju.edu.cn` 的账号密码）。

> 提示：登录成功后会话（cookies + token）与账号（勾选「记住密码」时）会保存到本地设置。下次启动若会话仍有效，会直接进入浏览态，无需重新登录。

### 步骤 6：选择批次后，类别区出现可选课程类别（显示中文名）

- **操作**：在批次下拉框中选择一个批次，观察类别区每一项的文字。
- **预期结果**：类别区（分段控件）出现该批次的可选类别， **显示中文名**。类别来自服务端批次配置的 `limitMenuList`，服务端收藏入口（`SC`）与课表查询（`QB`）被过滤不显示。若该批次无可用类别，列表区显示「暂无可用类别」。
    - 中文名按三级回退取名：服务端 `menuName` → 内置代码对照表 → 代码本身。抓包中 `menuName` 多为 null，因此通常走对照表：

      | 代码 | 显示名 | 代码 | 显示名 |
          | --- | --- | --- | --- |
      | `ZY` | 专业 | `YD` | 悦读 |
      | `TY` | 体育 | `KZY` | 跨专业 |
      | `GG01` | 公选课 | `TX01` | 大学数学 |
      | `GG02` | 导学/研讨/通识 | `TX02` | 大学英语 |
      | `GG06` | 科学之光 | `TX03` | 思政军事类 |
      | `MY` | 美育 | `TX04` | 计算机 |

    - **未收录的 code 回退显示代码本身**（不编造中文名）：参考脚本对照表未收录的 `GG03` / `GG04` / `GG05` 等，类别区就显示 `GG03` 这样的原始代码，属预期，不是显示 bug（见「四、失败排查表」最后一行）。
- **证据**：截图类别区（尽量截到含回退 code 的批次）。

### 步骤 8：卡片字段正确

- **操作**：任选一张课程卡片，逐项核对以下字段。
- **预期结果**：卡片包含：
    - **已收藏徽标**：收藏后卡片左上角显示「已收藏」徽标；
    - **课程编号**、 **课程名**（加粗）；
    - **学分**：格式「N 学分」；
    - **教师**：教师姓名；
    - **时间地点**：上课时间与地点；
    - **校区**；
    - **已选/容量**：格式「已选/容量: X/Y」；
    - **选中概率**：格式「选中概率: N%」或「—」（展示用估算值，见「五、已知限制」）；
    - **课程简介**：单行省略，鼠标悬停显示全文。
    - **右侧三个按钮**（自上而下）：
        - **收藏 / 取消收藏**（心形图标 + 文字，图标与文字不重叠）：未收藏显示「收藏」，已收藏显示「取消收藏」；悬停提示「收藏到本地收藏集」。
        - **立即报名**（主色按钮）： **单次**提交一次报名请求，结果马上弹出（只试一次），不做重试。悬停提示「立即提交一次报名请求，结果马上弹出（只试一次）」。
        - **加入抢课**（播放图标 + 文字）：把课程加入任务列表，按「定时开始 / 随机延迟 / 重复次数」 **持续**尝试，成功后自动停止。悬停提示「加入抢课任务，按定时与重试参数持续抢课，成功后自动停止」。
        - **区别一句话**：「立即报名」= 只试一次，马上看结果；「加入抢课」= 放进任务列表反复抢，直到成功或次数用尽。
        - **禁用规则**：课程 **已选**（`is_choose=="1"`）或 **已满**（`is_full=="1"`）时，「立即报名」与「加入抢课」 **同时**禁用，并各给原因 tooltip：
            - 已选 → 报名按钮「已选该课程，无需重复报名」、抢课按钮「已选该课程，无需再抢」；
            - 已满 → 报名按钮「课程已满，无法报名」、抢课按钮「课程已满，无法抢课」。 （两个按钮跟随同一套禁用规则，避免出现「能加入抢课却不能报名」的矛盾。）
- **证据**：截图一张完整卡片（含右侧三个按钮），以及一张已选/已满课程的按钮禁用 + tooltip 截图。

- **证据**：截图搜索结果并标注排序。

### 步骤 12：单个「加入抢课」→ 任务页出现任务；「一键开始全部抢课」→ 批量任务；按定时开始/随机延迟/重复次数运行，成功后停止并提示

- **操作**：
    1. 在选课页或收藏页某张卡片点击「加入抢课」按钮；
    2. 切换到「任务」页确认任务卡片出现；
    3. 在收藏页点击「一键开始全部抢课」（可取消勾选「跳过已满课程」）；
    4. 观察任务卡片上的「定时开始」开关、延迟区间（默认 0.5 ~ 1.5 秒）、重复次数（0=不限）。
- **预期结果**：
    - 点「加入抢课」后任务页出现该课程任务卡片，右上角弹出「已加入抢课任务 / 「课程名」已加入抢课」；对同一课程重复添加时提示「任务已存在 / 「课程名」已在任务列表中」；
    - 「一键开始全部抢课」为每个未跳过课程生成任务，提示「一键抢课 / 已加入 N 个抢课任务，跳过 M 个」；已在课表的课程与已满课程（勾选「跳过已满课程」时）被跳过；
    - 任务按配置运行：开启「定时开始」时状态显示「倒计时 Ns」，到点自动开始；每次尝试间隔在延迟区间内随机；重复次数达到上限或成功后停止；
    - 抢课成功：任务状态「成功」，进度区显示结果消息，右上角弹出「抢课成功」；失败弹出「抢课失败」；
    - **任务卡按钮随状态切换**：`等待中` →「开始」可用、「停止」禁用（若停止过且已尝试 > 0 次，文案为「继续」）；`运行中` →「停止」可用、「开始/继续」禁用；`已停止`/`失败` →「继续」可用、「停止」禁用；`成功` → 按钮文案「已完成」且两个按钮都禁用。
- **验收要点（第二批修复，逐条实测）**：
    1. **停止后继续**：任务运行中点「停止」→ 任务停止、状态变「已停止」、按钮变「继续」；再点「继续」→ 任务重新开抢（状态回「等待中」并进入「运行中」，尝试次数继续累加）。
    2. **「定时开始」开关切换即时生效**（不必重新点「开始」）：
        - 开启 → 若批次开始时间在未来，状态 **立即**显示「将在 N 秒后开始」并进入「倒计时 Ns」；若开始时间已过（或不可解析）→ **立即**开抢；
        - 关闭 → 正在倒计时时 **立即**取消定时器，状态回到「等待中」并提示「已取消定时，等待手动开始」；
        - 任务 **运行中**切换开关不打断当前轮次，只提示「任务运行中，定时设置已保存，下次启动生效」。
    3. **随机延迟 / 重复次数改动即时生效**：改完输入框（失焦即提交）后不必重启任务，下一次尝试就用新参数；非法输入（负数、非数字、超范围）会被拦截并回退成旧值；延迟区间填反（min > max）会自动交换。
- **证据**：截图任务页任务卡片、成功/失败提示，以及上面三条验收要点各自的前后对比截图。若任务立即失败，见「四、失败排查表」第 11 至 13 行。

    - 选课页课程列表被清空。
- **证据**：截图退出前后的对比（页签层 → 登录卡）。

### 步骤 14：收藏页「清空收藏」（二次确认）

- **操作**：
    1. 先确保收藏页有若干收藏（可复用步骤 10 造出的数据）；
    2. 在「收藏」页点击顶部「清空收藏」按钮 → 弹出警告 InfoBar（标题「清空收藏」，内容「确定清空全部收藏？（该操作无法撤销！）」，带「确定」「取消」两个按钮）；
    3. 先点「取消」确认数据不变，再点「清空收藏」→ 点「确定」。
- **预期结果**：
    - 点「取消」：只关闭确认提示，收藏列表不变；
    - 点「确定」：确认提示关闭，右上角弹出 InfoBar「成功！ / 已清空全部收藏！」；「收藏」页列表清空并显示空态文字「暂无收藏，可在选课页点击收藏按钮添加」；注意选课页 **已加载的卡片不会立即刷新**，「已收藏」徽标会保留到下次重新加载类别或重新搜索为止（清空收藏只刷新收藏页）；
    - 清空只作用于本地收藏集（本插件不使用服务端收藏），无法撤销。
- **证据**：截图清空收藏前后的收藏页对比与「已清空全部收藏」提示。

## 五、已知限制

1. **验证码全自动识别**：验证码由 ONNX 模型自动识别，偶发识别失败会自动换新验证码重试（最多 3 次），仍失败则需重试登录。无手动输入验证码的回退方案。
2. **收藏为纯本地实现**：收藏不读写服务端收藏接口（`favorite.do` / `queryfavorite.do`），换机器或清配置会丢失。
3. **选中概率只用卡片上的「已选/容量」两个数计算**：公式为 `(容量 - 已选) / 容量`，例如 `0/185` 显示 `100%`、`89/40` 夹取后显示 `0%`；服务端标记已满（`isFull=1`）直接显示 `0%`，容量缺失显示 `—`。 **与批次策略（先选先得/可选可退）无关**，也不再读取恒为 null 的 `numberOfFirstVolunteer`。非官方精确值，仅供参考。
4. **分页不依赖服务端 `totalCount`**：该字段服务端恒为 0，插件以「本页行数 < 每页大小」判定末页。
5. **「清空收藏」只作用于本地**：收藏页的「清空收藏」按钮只清本地收藏集（本插件不使用服务端收藏，不会调用 `favorite.do` / `queryfavorite.do`），无法撤销；任务的停止/移除在任务页逐卡操作，已被服务端接受的选课结果不受影响。
6. **取消倒计时要用「定时开始」开关**：倒计时期间任务尚未提交，此时「停止」按钮是 **禁用**状态，无法用它取消；把「定时开始」开关关掉即可立即取消倒计时并回到「等待中」。
7. **「重复次数」是每轮次数**：停止后点「继续」会重新计一轮（`repeat` 从本轮起点重新数），但 **累计尝试次数不归零**（`attempts` 一直累加）。若要真正从头开始，先移除任务再重新添加。
8. **「立即报名」只提交一次，不重试**：点「立即报名」向 `volunteer.do` 提交 **一次**报名请求（会话失效时自动重新登录一次并重试一次），结果即时弹 InfoBar；未开放 / 人数已满等场景直接展示服务端返回的 msg，轮询超时提示「未能确认结果，请稍后查看选课结果」。需要反复尝试请用「加入抢课」。报名期间重复点击同一门课会被忽略（提示「正在报名中，请稍候」）。
